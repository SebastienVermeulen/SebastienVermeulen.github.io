three.js

An example of an interactive Three.js implementation.

By dragging the across the window you can bend the dragon, try it out.

Implementation details

This project was a short one to learn and use Three.js, and WebGL. It is a simple testbed and example Javascript and GLSL to show of the Disney BRDF.

The material implements the regular metalic and roughness PBR workflows of course, but also: Sheen, Clearcoats, and simple SubSurfaceScattering.

To make it slightly more interesting I've added some some orbeting point lights in: red, green, and blue. As well as an ambient light, hemisphere light, and directional light. This should give a clear and readable sense of what the BRDF is capable of.

As you can see the model transitions through five different parameter sets:

    Jade, Shiny Copper, Pink Cloth, Pottery with a clearcoat, and Matte Gold.

Besides this the bending/deformation is done in the vertex shader to keep the performance smooth overall.
